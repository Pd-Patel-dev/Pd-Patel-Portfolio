RAG Workspace

A document question-answering app where users upload files and ask questions about their own documents using Retrieval-Augmented Generation, FAISS, Hugging Face embeddings, FastAPI, React, and PostgreSQL.

Problem

Users need trustworthy answers grounded in their own uploaded documents — not generic LLM output — with clear sources and secure multi-user isolation.

Solution

A full-stack RAG workspace: upload documents, embed with Hugging Face models, retrieve via FAISS hybrid search, and answer with cited context through a FastAPI + React stack backed by PostgreSQL.

What I built

  • Document Q&A app for uploading files and asking questions over personal corpora using RAG
  • Stack: Python, FastAPI, React, TypeScript, PostgreSQL, FAISS, and Hugging Face embeddings
  • Source citations so answers stay grounded in retrieved document chunks
  • Separate FAISS indexes per user for secure, isolated retrieval

Document upload

Users upload files and query their own documents through a React TypeScript frontend.

Embeddings

Hugging Face embeddings feed FAISS indexes for semantic retrieval over chunked content.

Source citations

Answers surface the document context used so users can verify claims.

PostgreSQL

Persistent metadata, auth, and app state alongside vector indexes.

Hybrid retrieval pipeline

Built a retrieval system that combines multiple strategies to surface useful information from uploaded documents:

  • Vector search over FAISS embeddings for semantic matches
  • Keyword search for exact term and entity hits
  • Query expansion and multi-query search to broaden recall
  • Result ranking and context filtering before generation

Security & reliability

  • JWT authentication for protected document and query APIs
  • Separate FAISS indexes per user to keep corpora isolated
  • Caching and retry handling for resilient retrieval and generation
  • Health monitoring to track service readiness and failures
