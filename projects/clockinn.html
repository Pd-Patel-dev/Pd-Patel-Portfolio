Problem

Small teams juggle paper timesheets, ad-hoc Slack messages, and error-prone spreadsheets — managers lose hours reconciling hours before every payroll run, and employees lack clarity on shifts and approvals.

Solution

A unified web app where managers publish schedules, employees clock in with audit trails, and payroll-ready reports export in one click — with JWT-secured roles so each person sees only what they need.

Project goals

Replace manual payroll prep with a trustworthy source of truth for hours worked. Optimize for managers who need fast approvals and employees who need a frictionless mobile clock-in experience.

  • Cut weekly admin overhead by 80% versus spreadsheet workflows
  • Support teams up to 50 with predictable performance and clear RBAC
  • Ship zero-trust auth patterns — short-lived JWTs, refresh rotation, and audit logs
  • Deliver PDF and Excel payroll exports accountants can use immediately

Shift scheduling

Drag-and-drop weekly grids, recurring templates, and conflict detection before shifts go live.

Clock-in / out

Web and mobile-friendly punches with optional geofence validation and manager override trails.

Role-based access

Manager, employee, and payroll roles with scoped APIs — no cross-tenant data leakage.

Payroll exports

One-click PDF summaries and Excel breakdowns with overtime, PTO, and approval status columns.

Frontend

Next.js with SSR for fast first paint on manager dashboards. React Query caches shift data; optimistic updates for approvals keep the UI responsive on slow networks.

Security

bcrypt password hashing, HTTP-only refresh cookies, and per-route permission checks. All punch mutations write to an append-only audit log for dispute resolution.

Scheduling

Publish weekly rosters with role assignments, swap requests, and email digests when schedules change.

Clock-in / out

Timestamped punches with break rules, late flags, and manager corrections that preserve the original entry.

RBAC

Three roles — Manager, Employee, Payroll — each with dedicated navigation and API scopes enforced server-side.

Payroll export

Generate period-close reports as PDF for review or Excel for import into QuickBooks and similar tools.

Role-based workflow

Click each role to see how they interact with the system.

Managers create teams, publish shift templates, approve time-off, and review flagged punches. They see org-wide dashboards, can override missed clock-ins with notes, and lock pay periods before export.

Measurable impact

  • 80% reduction in weekly admin time for managers running payroll prep
  • 0 auth incidents across penetration-style testing of JWT and session flows
  • 50-employee ceiling validated with load tests on schedule and punch APIs
  • 1-click export replaces multi-step spreadsheet merges accountants used before
  • Audit-ready trails for every punch edit — disputes resolved in minutes, not days
