Problem

Job seekers receive hundreds of mixed emails — applications, rejections, interviews, and spam — with no reliable way to triage what matters without manual sorting every day.

Solution

A classical NLP pipeline using TF-IDF features and scikit-learn models (Logistic Regression, Linear SVM, Naive Bayes) trained on 1,500 realistic recruiting emails and selected with macro F1 via 5-fold cross-validation.

Project goals

Build a reliable, interpretable email classifier for job-search workflows using entry-level ML practices — clean data, clear evaluation, and model comparison.

  • Sort emails into 6 categories: applications, assessments, interviews, offers, rejections, and related status
  • Create a 1,500-email dataset spanning companies, roles, subjects, formats, and reply patterns
  • Compare Logistic Regression, Linear SVM, and Naive Bayes with an 80/20 split and 5-fold CV
  • Select the best model using macro F1 score and persist it with Joblib

Gmail integration

OAuth2 sync with incremental fetch, thread-level grouping, and preprocessing for HTML stripping and token normalization.

Confidence routing

Each stage emits a score; only low-confidence items escalate — keeping LLM API costs predictable.

Analytics dashboard

Track application funnel, response rates, and model drift with filters by company and date range.

Safe fallbacks

Graceful degradation when Gmail quota or model endpoints fail; queue retries with exponential backoff.
