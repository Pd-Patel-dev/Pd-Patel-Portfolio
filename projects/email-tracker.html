Problem

Job seekers receive hundreds of mixed emails — applications, rejections, interviews, and spam — with no reliable way to triage what matters without manual sorting every day.

Solution

An automated Gmail-connected system that classifies threads in milliseconds, escalates only uncertain cases to heavier models, and surfaces a clean dashboard for application status.

Project goals

Balance accuracy, inference cost, and response time. Rule-based filters handle obvious cases instantly; BERT handles semantic nuance; LLM catches long-tail edge cases only when confidence drops below threshold.

  • Reduce false positives 30–40% versus rules-only baseline
  • Support 50+ concurrent API users with sub-500ms responses
  • Export ONNX models for 3× faster CPU inference in production
  • Maintain auditable confidence scores per classification stage

Gmail integration

OAuth2 sync with incremental fetch, thread-level grouping, and preprocessing for HTML stripping and token normalization.

Confidence routing

Each stage emits a score; only low-confidence items escalate — keeping LLM API costs predictable.

Analytics dashboard

Track application funnel, response rates, and model drift with filters by company and date range.

Safe fallbacks

Graceful degradation when Gmail quota or model endpoints fail; queue retries with exponential backoff.

Backend

FastAPI with async workers, structured logging, and health checks. ONNX Runtime serves quantized BERT for batch and single inference paths.

Frontend

React SPA with optimistic UI, skeleton loaders, and accessible status chips. API client handles pagination and real-time poll for sync jobs.

Measurable impact

  • 91% precision on held-out test set across 12 application categories
  • 30–40% fewer false positives vs. rules-only — users trust the inbox again
  • 3× inference speedup after ONNX quantization without meaningful accuracy loss
  • <500ms p95 API latency under load tests simulating 50 concurrent users
  • ~55% cost reduction on LLM calls by routing most traffic through rules + BERT
