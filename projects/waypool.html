Problem

Carpool and local ride operators rely on phone calls and manual dispatch — riders wait without visibility, drivers chase payments, and admins cannot see fleet status in real time.

Solution

Separate Rider, Driver, and Admin apps connected through a WebSocket-backed API — live trip state, automated fare splits, and Stripe Connect payouts without end-of-day reconciliation spreadsheets.

Project goals

Deliver a production-grade mobility stack where location updates and trip events feel instant, payments settle automatically, and ops teams can intervene from a single admin console.

  • Support 500+ concurrent connections with predictable WebSocket fan-out
  • Keep trip event latency under 100ms for rider and driver UIs
  • Ship three React Native apps sharing auth, maps, and API contracts
  • Automate driver payouts via Stripe Connect with transparent fee breakdowns

Real-time WebSocket

Room-based channels per trip — location pings, status changes, and chat propagate in under 100ms.

Stripe Connect

Split fares, hold platform fees, and trigger instant or scheduled payouts to verified driver accounts.

React Native

Shared design tokens and API hooks across Rider, Driver, and Admin builds for iOS and Android.

Live GPS tracking

Background location with battery-aware throttling, geofenced pickup zones, and ETA recalculation.

Real-time layer

Socket.io with Redis adapter for horizontal scale. Trip rooms isolate events; heartbeat and reconnect logic keep mobile clients consistent after network drops.

Maps & matching

PostGIS-backed driver queries, surge-aware pricing hooks, and map-matched polylines for accurate ETAs shown to riders waiting at pickup.

Three-app platform

Each app targets a distinct persona with tailored flows while sharing authentication and trip contracts.

Rider

Request rides, track driver ETA on a live map, pay in-app, and rate completed trips.

Driver

Accept requests, navigate turn-by-turn, manage availability, and view Stripe payout history.

Admin

Monitor active trips, resolve disputes, adjust surge zones, and verify driver onboarding documents.

WebSocket events

Trip lifecycle broadcasts — assigned, arrived, started, completed — with idempotent handlers on reconnect.

Stripe Connect

Express accounts for drivers, application fees for the platform, and webhook-driven payout reconciliation.

React Native core

Expo-managed builds with native modules for background geolocation and push notifications.

Ops dashboards

Admin heatmaps for demand, cancellation reasons, and fleet utilization during peak windows.

Measurable impact

  • 500+ concurrent users sustained in load tests without WebSocket degradation
  • <100ms median event delivery from server emit to client handler
  • 3 production apps sharing one API contract and design system
  • 5 hours saved per driver weekly by eliminating manual payment reconciliation
  • Automated payouts via Stripe Connect reduced settlement errors to near zero
